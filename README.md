# Netflix-Project

This project explores the Netflix Titles dataset from Kaggle using
MySQL.The goal is to analyze Netflix's content catalog and answer
business-related questions using SQL.

Dataset

-   Source: Kaggle
-   Records:8,807
-   Columns: 12

The dataset contains information about Netflix Movies and TV Shows,
including:

-   Title
-   Type
-   Director
-   Country
-   Date Added
-   Release Year
-   Rating
-   Duration
-   Genre


## Tools Used

-   MySQL
-   MySQL Workbench

## Business Questions Answered

1.  How many titles are available?
2.  How many Movies and TV Shows are there?
3.  Which ratings are most common?
4.  Which countries have the most Netflix content?
5.  How many Nigerian titles are available?
6.  Which release year has the most titles?
7.  Which year did Netflix add the most content?
8.  Which month had the highest number of additions?
9.  Which directors have the most titles?
10. What is the average duration of Netflix movies?



## Key Findings

-   Netflix contains 8,807 titles.
-   Movies account for approximately 70% of the catalog.
-   TV-MA is the most common rating.
-   Netflix added the highest number of titles in 2019.
-   The highest number of releases occurred in 2018.
-   Rajiv Chilaka has the most titles among directors.
-   The average movie duration is 99.58 minutes.
